## 1. The diagnosis, in detail (for the record)

Two genuine bugs, found by refusing to accept "trivial boundary case" as an explanation and instead using the collapse argument as a debugging tool:

1. **Off-by-one:** `spy_part` was seeded at `w` and only ever multiplied by returns from index 1 onward, silently skipping the first trading day's return entirely. Traced to the exact iteration (i=1) where the running portfolio value first diverged from the reference buy-and-hold series, and confirmed the divergence's size matched the missing day's return almost exactly (a ~1.4% pricing gap, compounding into the observed ~0.22% annualized CAGR difference over seven years).
2. **Timezone stripping:** the month-end detection set was built by calling `.values` on a timezone-aware pandas index, which converts to naive UTC-based `numpy.datetime64` — comparing those against the timezone-aware `pandas.Timestamp` values being iterated over in the loop always returns "not equal," so the monthly family had silently never rebalanced, in either the round that introduced it or the round that claimed to re-verify it. Found by directly counting matches (0, when 84 were expected) rather than trusting the family label.

Both are now fixed, both fixes independently verified (exact-zero difference at the *w*=1 collapse point; the correct rebalance count), and the three-family comparison re-run to a clean 0.00000% shift.

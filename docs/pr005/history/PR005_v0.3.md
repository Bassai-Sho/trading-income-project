## 1. The dominance test, replacing G3's old "OR" gate — worked through

Real numbers, computed this round, no signal involved:

- E3 buy-and-hold total-return CAGR: **11.65%**
- E3 buy-and-hold max drawdown: **−33.70%**
- Static-mix property (verified in §0 item 1): a mix at weight *w* has drawdown ratio ≈ *w* and CAGR deficit ≈ (1−*w*) × (CAGR_BH − cash rate), **and identical Sharpe to buy-and-hold at every *w*** — which is exactly why Sharpe alone can never distinguish skill from dilution, at any threshold.

**New G3 (dominance test):** let *w** be the rule's own realized drawdown ratio on E3 (its max drawdown ÷ buy-and-hold's). The rule passes iff its realized CAGR **exceeds** what a static mix at that same ratio *w** would have earned — i.e., it must beat the "free" dilution benchmark at its own risk level, not merely tie an unrelated aggregate statistic. This closes both F1 and F2 from this round's review in one clause: there is no *w* at which a static mix can pass (it exactly meets its own benchmark, never exceeds it), and the test no longer depends on an assumed CAGR-deficit constant.

**Still needed before this is freeze-ready:** the real E3 cash rate (DFF, daily, via `market_data_store`'s existing FRED fetcher) — the CAGR-deficit side of the frontier is currently illustrative only, built on a placeholder rate, and is not to be treated as final.

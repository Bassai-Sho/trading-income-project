## 2. Hypotheses, with the corrected prior

**Stated prior, corrected:** Faber's own single-asset S&P 500 result (1900–2005): CAGR 10.66% (timed) vs. 9.75% (buy-and-hold) — timing is *slightly better*, not "comparable or slightly lower" as v0.1 assumed; Sharpe 0.43 vs. 0.29; max drawdown 49.98% vs. 83.66% (ratio 0.597); time in market 69.77%; 0.67 round-trip trades/year; 63% winning trades. If this replicates on modern data, the honest expectation is **similar-or-better return with materially smaller drawdown** — a stronger prior than v0.1 stated, now anchored on the actual single-asset table rather than assumption.

H0/H1/H2 unchanged in substance from v0.1.

## 3. Rules

Unchanged from v0.1's T1/V2/V3 definitions, with the pinned conventions from §0 (items 4, 5, 10, 13) now part of the frozen spec rather than left to the two G1 implementations to guess independently.

## 4. Data and integrity (gate G0)

**Primary:** SPY daily OHLC, unadjusted, plus dividends, yfinance, 1993–2024 (confirmed available). **New split check:** assert no unhandled stock split exists in the vendor's split records for any series under test; QQQ (V3) is known to have split 2:1 on 2000-03-20 and must be explicitly adjusted for or excluded from that date. **Loader requirement** (carried from PR-004): `end` is exclusive; request `end + 1 day`, assert the last row matches. **Calendar:** `exchange_calendars` XNYS for month-end dates. **New asserts:** no NaN in the price or dividend series; no forward-filled rows; dividend rows ≈ 4/year with positive amounts and no duplicate ex-dates; OHLC consistency (`high ≥ max(open,close,low)`, etc.); ≥ 10 months of data (including the current month) before every evaluation month.

## 5. Eras

Unchanged windows from v0.1. **Reweighted role:** G2 (E1+E2, containing 2008–09) is now the primary carrier of the drawdown claim's evidence, with a pre-registered negative control (§0 item 8); E3 is a regime-consistency check on the same claim, disclosed as historically the harder regime for a monthly-signal rule (fast V-shaped crashes rather than slow bears) rather than presented as an equally-powered primary test.

## 6. Costs

## 7. Gates, corrected

- **G0** Data integrity, including the new split check (§4). Failure stops the item.
- **G1 Implementation**, with the 1bp tolerance and mismatch-printing convention (§0 item 11).
- **G2 (H0), replication + negative control, on Stage R, E1+E2.** Bands, now derivable rather than assumed: max drawdown ratio ≤ **0.60 + a stated leniency margin of 0.05** (i.e., ≤ 0.65, since 0.597 is the point estimate and some slack is needed for a 31-year modern sample vs. a 105-year one); CAGR within **−2 to +4 percentage points** of buy-and-hold's (asymmetric, reflecting the corrected prior that timing was slightly *better*, not just comparable); time in market 55–85% (centred on 69.77%). **Pre-registered negative control: an inverted-signal variant must fail this gate** (fail = does not achieve the drawdown reduction). Failure protocol matching PR-004: one investigation, at most one fix-and-rerun, unattributable miss closes the item.
- **G3 (H1), value test, on Stage V, E3 (regime-consistency check, not sole primary — §5).** Sharpe ≥ buy-and-hold's Sharpe **OR** (max drawdown ≤ 0.60 × buy-and-hold's **AND** E3 CAGR ≥ buy-and-hold's − 4pp) — the added return floor on the DD arm, closing the static-mix/always-flat gaming routes (§0 items 6–7). Minimum 40% time-in-market required for the gate to evaluate at all.
- **G4 Economic report** (not gated): unchanged list from v0.1, plus the boundary-sensitivity report (§0 item 9) and the blend test (H2) at 25/50/100% allocation.
- **G5 (E4, once):** single named, hashed script; report only.

**Verdict categories, corrected 2×2:** the four combinations of {Sharpe better/worse} × {DD-arm passes/fails, with its return floor} map to: both-better → CONFIRMED; DD-arm passes with the return floor but Sharpe worse → CONFIRMED (value-via-drawdown, labelled as such, not conflated with a Sharpe-driven confirmation); Sharpe better but DD-arm fails → CONFIRMED (value-via-return); both fail → **value-CONTRADICTED** (renamed from CONTRADICTED, since G2's replication result is separate and unaffected — a rule can replicate the historical pattern and still be value-contradicted in this specific window). **INCONCLUSIVE** only applies below the 40% time-in-market floor or on a G0/G1 issue.

**Decision rule:** proceed to forward paper trading iff G0–G2 pass (including the negative control) and G3 is not value-CONTRADICTED. **Paper trading itself requires a pre-registered duration and kill criterion, stated before the first live signal** — not yet written; this is now an explicit freeze condition (§8).

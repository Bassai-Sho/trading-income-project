# Trading AI 📈

**Your local AI research assistant for systematic trading.**

---

## Chat Profiles

| Profile | Use for |
|---------|---------|
| 🔍 **Research** | News, prices, market data — web search enabled |
| 🧠 **D-A-C** | Deep analysis sessions — thinking mode on |
| ⚡ **Quick Chat** | Fast Q&A — no tools, direct responses |

## Tips

- **D-A-C sessions:** Switch to 🧠 D-A-C profile for full reasoning chain visibility
- **Slow responses are normal:** At 2.7 tok/s on the Arc iGPU, a 500-token response takes ~3 minutes
- **Thinking mode:** When enabled, you'll see a 💭 collapsible reasoning block before the answer
- **Tools:** Web search automatically fetches the best article from results

## Quick Actions

After every response, action buttons appear for **Retry**, **Clear**, **D-A-C**, and **Toolkit**.
